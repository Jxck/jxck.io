# Verifiable Credentials による個人情報収集の最小化

## Intro

マイナンバーカードや JPKI を用いて、本人確認する方式への移行が急がれている。

しかし、確認方法が変わっても、そこで取得した情報を DB に保存していては、漏洩のリスク自体はなくならない。

個人情報自体を渡さずに、必要な確認を行うことができれば、そのリスクも減らせるだろう。

&nbsp;

ここで活用が期待されているのが、 Verifiable Credentials だ。

&nbsp;

この記事は、**サイバーセキュリティアドベントカレンダー** 4 日目である。

&nbsp;

## 情報の「収集」と「確認」

従来は、成年であるかを確認するために、生年月日を収集する必要があった。

しかし、本当に知りたいのは「成年であるか」という Boolean だけで、生年月日という情報自体ではない。

同様に、マッチングアプリでは「未婚である」、学割では「学生である」などの情報を取得したいが、住民票や学生証自体が必要なわけではないという場面も多々あるだろう。

こうした場合に、その事実の証明だけを取得し、その真正性を確認する方法として活用できるのが Verifiable Credentials だ。
