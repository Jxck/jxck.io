****# ダークウェブで LLM がどう使われているか

情報漏洩が後を絶たない。

我々もいつ狙われてもおかしくない。というかまあ、狙われてもいるのだろう。

なぜこんなに急に増えたのだろうか、という話には、いろんな憶測がある。

相関があるだけなのか、因果があるだけなのか、眉唾な話もいっぱいある。

そんななか、ダークウェブ関連で契約しているサイバーセキュリティの KELA さんから、

すごく有用なレポートが届いた。

この中身について、知っておいた方が良い話を抜粋して紹介する。

# Adversarial LLMs (敵対的 LLM)

もちろん攻撃者も LLM を使っているわけだ。

しかし、 Claude を始めとした大手ベンダーの LLM にはセーフガードがかけられていて、

「悪いことしようとしてる！拒否します！」と動きが止まってしまう。

ジェイルブレイクと言って、それを迂回するために AI を騙す手法もちらほら出るが、

ベンダーが監視して「こいつ悪用としてるな」と思ったら垢バンするだけだから、

大きな攻撃を成立させるのは難しい。

そこで Open Weight Model である。

世の中にはすでに Claude や Codex の先端モデルと近いところまで育った知能で

セーフガードがついていないものが公開されていて、

それを手元で自由に動かせるようになっている。

Kimi-K3 とか GLM-5.3 とか Qwen-3.8 とか、そういうものだ。

小さめのモデルなら Mac Studio とか並べてお家で動かすこともできるので

それを使って色々悪いことをすることもできる。

しかし、ある程度上位になると、動かすのにそれなりのインフラが必要である。

GPU とか、メモリとか、それを動かせる電源と冷却のあるデータセンターと、構築の知識。

ダークウェブには今、そういう LLM をホスティングして、他の攻撃者が必要に応じて借りて使えるような

サービスが提供されている。

他にも、「悪用を前提とした LLM(MessiahGPT)」とか「盗んで集めた AI のトークン(ChatGPT や Grok)」とか「ジェイルブレイクしたアクセス」など、いろんなパッケージが売られていて、攻撃者はニーズに応じてそれらを調達して攻撃しているわけだ。

でも、やっぱり最終的には、ログが残らず、無限に動かせて、セーフガードが無い、 Local LLM の悪用向けホスティングサービスの需要が凄くて、ダークウェブ上でも一大市場を築いているわけだ。

こういうものを、敵対的 LLM と呼んでいるということだ。

# 敵対的 LLM 脅威アクター

脅威アクターというのは、要するに「悪いことする集団」と見なされている人たちということだ。

先日捕まった Qilin とか、有名どころだと Anonymouse とかそういう集団。

そして、今だと GLM-5.2 をホストして、API を提供する脅威アクター業者が確認されている。

専用のハードを組んで、高速な応答と、 OpenAI 互換と、ログなどを一切残さない完全匿名利用を売りにしている。

さらに、 AI の実装をトータルでサポートするコンサル業者も確認されている。

知識のない人に、カスタマイズを提供したり、トレーニング支援したり、攻撃に特化した RAG を提供したり。

何というか、表の世界よりもサポートが充実しているのではないか。

だから、「AI を使って攻撃のコストが下がった」というだけでなく、その「AI を使って攻撃するコストも下がった」状態なわけだ。

ちょっと元手があれば、誰でも攻撃キャンペーンに加担できる。

攻撃が増えている理由も、ちょっと解像度が上がってきた。

# ハッキングボット

もちろん自動化も進んでいる。

例えば、タイムズで話題になった KYC、本人確認のために顔写真や免許をカメラで撮るあれである。

漏洩の話とは別に、あれを突破すれば車が借り放題で、足のつかない車は犯罪には結構重要なツールなのである。

この KYC 突破のために、ディープフェイクで顔を作り、まばたきや顔の向きをリアルタイムで指定できるアプリなどが売られている。

他にも、マルウェアやフィッシングサイト、ファイアウォールの突破などは、ダークウェブに誰かが使ったパッケージが売られていて、攻撃者はそれを買って攻撃に使うという流れが主流だったが、

最近はそういう機能がまるっと知識として入っていて、指示すればローカルで動く Agent の形で売られているらしい。

Agent があれば、プロンプトを書いて指示をもらい、人間が実行するまでもない。

OS やツールを Agent が直接操作してくれる。つまり、「アレを攻撃して」と言えば、全自動でやってくれるわけだ。

METATRON という Qwen-3.5 ベースの OSS ペンテストツールなんかを使って、相手を偵察し、分析して脆弱性をみつけ、エクスプロイトまで出してもらう。

攻撃には、手法や使えうペイロードがはいった RAG を連携して、必要に応じて GitHub からツールを取ってきて、防御が破れるまで色々ためしてくれる。

そういうものが、確認されている範囲では Ollama 版が 500 ドル、 Claude 版が 900 ドルといった価格で使える。

攻撃が成功したリターンが見込めるなら、だいぶ安い。

つまり、もう攻撃なんて Steam インストールしてゲームを起動するのと同じくらいの感覚でできるのだ。

専門知識もいらない。やろうと思うだけ。

それなら攻撃し放題だし、漏洩はとまらないだろう。

# 防御側はどうするか？

KELA は、こういうものに対する防御ソリューションを出している会社だから、

ダークウェブ市場の動向を注視したり、 AI による攻撃の特徴を踏まえて監視する必要があるという話になる。

WAF のルールやリミットを AI に合わせて調整し、AI 特有の応答速度や規則的なパターンを、単一イベントではなく、連続のシーケンスで検知する必要がある、といった宣伝につなげているわけだ。

では、それはいいとして我々はどうだろうか。

一応、 Project Logos をやったことで、自社の製品をセキュリティスキャンするハーネスは作った。

でも、攻撃者が使っているような、セーフガードのない Local LLM の環境はできていない。

「Kimi-K3 とか使ったほうがいい」という話はしたのだが、ちょっと金がかかりすぎるということで却下されてしまった。

でも、 GLM-5.3 が出て、これは Anthropic の NIST も、「**十分にヤバいモデルだから、これがセーフガード無しで出てるのはよくない**」と認めてしまうくらい性能がいい。それなら、 Kimi-K3 の半分くらいのコストで動きそうだ。

とりあえず、従量課金だが一旦 AWS で試そうかという話がでているから、そこで試して成果が出たら、最終的にはそのくらいのモデルは自分たちで飼って手なづけておく必要がある、となるのではないだろうか。

あと、たぶんそれに合わせて、 Mythos のパブリックプレビューがはじまりそうだ。

ちゃんとサイバーセキュリティ防御に従事している、セキュリティのチームがあれば、申請したら使えるという話がやっと降りてきた。

[https\://www\.anthropic.com/news/cyber-verification-program](https://www.anthropic.com/news/cyber-verification-program)

セキュリティチームがいて、 Mythos にアクセスできたとしても、簡単には使いこなせないだろう。

でも、もう Logos を持っているうちらは、モデルを差し替えるだけだ。

無理やりにでも、作っておいてよかった。

ただ、 Logos の範囲は、製品のスキャンだけである。

我々という会社自体を守ると言うと、 kintone や garoon に脆弱性が無ければそれで足りるかと言うと、また話が別になる。

- 外からやってくる攻撃をどう防ぎ切るか
- 中で感染したり騙されたりする社員をどう守るか

前者は、 WAF などの導入である。それも、ただ DDoS を緩和したり、定型パターンに対応するだけでなく、今の AI 攻撃にもある程度対応できるようなものだ。ログインを 2 万回試されていたのに、気づかなかったなんてことがないような、そういう対策である。

後者は、マルウェアやフィッシングに引っかかるのを防いだり、ひっかかっても大丈夫にする対策である。ずっとやっているサプライチェーン攻撃周りの対策や、 1Password への以降。あと、 Bets で Sakito が言っていた「開発環境をまるっとサンドボックスに移す」といったことをちゃんとやっていかないと、防ぎきれないところまできた。

# まとめ

正直、今の時代は「狙われたら終わり」だと思う。

アサヒを攻撃した Qilin のメンバーが捕まったが、「[日本は世界最悪のコンピュータセキュリティ体制](https://news.yahoo.co.jp/articles/232fc93e84cb02201877ddd9d77051460fb00cd1)」と言っているから、日本は攻撃者市場にとって、標的市場なのだろう。

今まだ攻撃されたニュースが出ていない会社は、これでいうと 1, 2, 3 のどれかで、 4 の会社なんかそうそう無いと思う。

1. もう攻撃されたが、それにすら気づけていない
2. たまたままだ攻撃されていない
3. 攻撃する価値が無くて相手にされていない
4. 攻撃しても固くて落とせない

我々が今どれであるかはわからないが、できれば 4 でありたい。

ただ、今の状態でマジで狙われたら、まあまあ厳しいと思う。

せっかくここまでずっと頑張って来たのだから、できれば乗り切りたい。

そのためには、だいぶ分の悪い戦いだし、全然安心できるフェーズではないということだ。

世知辛い世の中である。
