Stand-Up Tech Talk: エコシステム三部作

Intro

Stand-Up Tech Talk とは、スライドなし、マイク 1 本のみの登壇形式である。

ここ 3 年かけて行った、Web のエコシステムに関する Stand-Up Tech Talk 三部作を公開する。

Web エコシステムとサイバースペース地政学

2026/09/12 フロントエンドカンファレンス福岡 (60min)

頻発するサプライチェーン攻撃と、Web エコシステムの生態系の変化に鑑み、Web 開発が受ける影響について。

(サプライチェーン攻撃で npm などが連日問題になっていた時期、AI による情報漏洩が連日報道される直前の時期)

技術的福祉の受容、および Web 開発との「出会い直し」

2025/11/16 JSConf JP 2025 (30min)

エコシステムを用いた Web 開発における「技術的貧困」に対して、AI が「技術的福祉」たりえるか。それを受容するために、開発者に迫られることになった Web 開発との向き合いなおしについて。

(Agent を用いた開発が一旦は市民権を得て、開発の方法が変わりつつあったが、まだ個々のエンジニアのなかで、技術者というアイデンティティが揺らいでいた時期)

Web エコシステムの人文社会学的解釈

2024/09/07 Web Developer Conference 2024 (60min)

「Web はエコシステムで作るもの」という前提をおきながら、そのエコシステム側の重力に踊らされ、常に「刷新」「剥がし」に追われるエンジニアは、価値の創出をどう説明できるか。また、その状態は「技術的貧困」に陥っているのではないか、という解釈について。

(AI 開発前夜、まだ人間がコードを手で書き、書ききれない部分を OSS に依存して、それがエコシステムとして回っていた時期)
