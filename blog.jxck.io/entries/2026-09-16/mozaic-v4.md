# mozaic.fm v4 Release Note #1 - Overview

## Intro

mozaic.fm v4 をリリースした。

かなり大幅ななアップデートになる。


## はじめに

URL 等は変わってない。

https://mozaic.fm

しかし、これを開くと接続できない人もいるだろう。決して落ちてるわけではない。

その理由は次回以降、今回の技術的変更について解説する。

サイトにアクセスできなくても、Spotify や Apple のアプリでの視聴はこれまで通り可能だ。

Podcast はそもそも Podcast アプリで聞くものなので、その範囲はこれまで通りの互換性を維持している。


## 連載

この Blog(blog.jxck.io)と mozaic.fm は、新しい技術を試す土台として活用してきた。

しかし、主に静的サイトとして、高速化の技術を徹底的に詰め込んできており、Blog も Podcast も近いスタックだった。

今回、mozaic.fm はより動的なアプリケーションに舵を切ることで、静的サイトである本 Blog では試せないものをより詰め込んでいくことができた。

実際に詰め込んだ技術スタックについては、連載の形で紹介したいと思う。

1. ネットワーク編
2. UI 編
3. VTT 編
4. LLM-Wiki 編

一部はすでに mozaic.fm 自体で話しているが、そこに収まらなかった技術的な変更だ、まだまだ残っている。

- ep213 mozaic.fm v4 release note | mozaic.fm
  - https://mozaic.fm/episodes/213/mozaic-v4-release.html


## Outro

めったに更新しないので、v3 だと勘違いして作業していたが、実は v4 だった。

以前 Opus でも刷新を試みたが思ったような成果にならず、あきらめていたが、Fable が出てから見違えるほど進んだ。

AI のおかげで、少ない時間でいろいろな技術を試せるようになったので、今後もこの mozaic.fm を土台に、色々試していきたい。
